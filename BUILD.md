# Build JARVIS APK

1. Install Android Studio.
2. Open this folder as an existing Android Studio project.
3. Let Gradle sync and install any requested Android SDK components.
4. Connect an Android phone with USB debugging enabled, or use an emulator.
5. Run the app with the green Run button.
6. To create the APK: Build -> Build Bundle(s) / APK(s) -> Build APK(s).

The current version is a UI prototype/simulator. Device switches change local app state.
The next stage is connecting the app to the physical JARVIS hub over the local network.
